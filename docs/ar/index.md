# البرمجة ينبغي أن تكون طبيعية باللغة العربية.

ركن (Rukn) لغة برمجة تجريبية تجعل العربية جزءًا أساسيًا من كتابة الشيفرة. التنفيذ الأولي مفسّر صغير مكتوب بلغة Rust. الهدف الحالي محدد: صياغة واضحة، وأخطاء مفهومة، واختبارات لكل ميزة منفذة.

[ابدأ بأول برنامج](/ar/guide/getting-started){.VPButton .medium .alt}
[اقرأ مواصفات اللغة](/ar/reference/specification){.VPButton .medium}

## ما الذي يعمل الآن؟

- كلمات محجوزة عربية ومعرّفات Unicode.
- أرقام عربية هندية وفارسية وأرقام ASCII.
- أعداد ونصوص وقيم منطقية وقيمة شبيهة بالعدم.
- متغيرات وعمليات حسابية ومقارنات ومساواة.
- أقواس وتعليمات تنتهي بالفاصلة المنقوطة ورسائل خطأ عربية.
- مكتبة Rust وواجهة سطر أوامر واختبارات وحدات.

## ما الذي لم يُنفّذ بعد؟

لا توجد حاليًا دوال أو حلقات أو أنواع يعرّفها المستخدم أو وحدات أو مدير حزم أو آلة افتراضية للبايت كود أو مترجم أصلي أو تكامل IDE أو مترجم مكتوب ذاتيًا. هذه أهداف لاحقة وليست ميزات موجودة.

## أول برنامج

```rukn
# examples/hello.rukn
دع الاسم = «العالم»؛
اطبع(«مرحبًا يا » + الاسم)؛
دع الناتج = ٦ * ٧؛
اطبع(الناتج)؛
```

الناتج المتوقع:

```text
مرحبًا يا العالم
42
```

## مبادئ التصميم

1. **العربية أولًا وليست العربية وحدها.** الكلمات المحجوزة ورسائل الخطأ عربية، مع دعم الأرقام المعتادة وعوامل مألوفة للتوافق.
2. **قواعد صغيرة قبل قائمة ميزات ضخمة.** تقود المواصفات والاختبارات عملية التنفيذ.
3. **أخطاء مفيدة.** تعرض الأخطاء السطر والعمود وتوضح سبب فشل العملية.
4. **دلالات صريحة.** لا يوجد تحويل ضمني بين الأنواع في النسخة الأولى.
5. **تطوير علني.** نفرّق بين المنفذ والمقترح ونوثق القرارات في تغييرات قابلة للمراجعة.

## حالة المشروع

**تجريبي، قبل ألفا.** لا يصلح ركن للاستخدام الإنتاجي، وقد تتغير قواعده قبل تثبيت مواصفات الإصدار 1.0.
