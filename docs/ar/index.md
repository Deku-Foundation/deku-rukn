## برنامج صغير من البداية إلى النهاية

المثال التالي هو نفسه الملف `examples/hello.rukn` الذي يجري اختباره ضمن CI.

```rukn
# أول برنامج بلغة ركن
دع الاسم = «العالم»؛
اطبع(«مرحبًا يا » + الاسم)؛
دع الناتج = ٦ * ٧؛
اطبع(الناتج)؛
اطبع(صحيح == خطأ)؛
اطبع(صحيح أو خطأ)؛
```

الناتج المتوقع:

```text
مرحبًا يا العالم
42
خطأ
صحيح
```

## حالة المشروع

**تجريبي · قبل ألفا · غير مخصص للاستخدام الإنتاجي.**

يدعم المفسّر الحالي الإسناد والنطاقات المحلية والشروط وحلقات «بينما» المحدودة والدوال المسماة ومراجع الدوال كقيم واستدعاء الدوال الأعلى رتبة والمعاملات والإرجاع والعودية والقوائم غير القابلة للتعديل والفهرسة من الصفر والدالتين `طول` و`أضف`. لم تُنفذ بعد الإغلاقات وتعريف الدوال المتداخلة والسجلات/الخرائط والوحدات ومدير الحزم وآلة بايت كود والترجمة الأصلية وتكامل المحررات والبناء الذاتي.

الأولويات المباشرة هي مواصفات دقيقة قابلة للاختبار، وتشخيصات موثوقة، وسياسة واضحة لمعرّفات Unicode، واختبارات تمنع التراجع، وبناء متكرر للتوثيق.
