## برنامج صغير من البداية إلى النهاية

المثال التالي هو نفسه الملف `examples/hello.rukn` الذي يجري اختباره ضمن CI.

```rukn
# أول برنامج بلغة ركن
دع الاسم = «العالم»؛
اطبع(«مرحبًا يا » + الاسم)؛
دع الناتج = ٦ * ٧؛
اطبع(الناتج)؛
اطبع(صحيح == خطأ)؛
```

الناتج المتوقع:

```text
مرحبًا يا العالم
42
خطأ
```

## حالة المشروع

**تجريبي · قبل ألفا · غير مخصص للاستخدام الإنتاجي.**

لا يدعم ركن حتى الآن الدوال أو الحلقات أو الوحدات أو المجموعات أو مدير الحزم أو آلة بايت كود أو الترجمة الأصلية أو تكامل المحررات أو البناء الذاتي. هذه أهداف بحث وتطوير مستقبلية وليست ميزات موجودة.

الأولويات المباشرة هي مواصفات دقيقة قابلة للاختبار، وتشخيصات موثوقة، وسياسة واضحة لمعرّفات Unicode، واختبارات تمنع التراجع، وبناء متكرر للتوثيق.
