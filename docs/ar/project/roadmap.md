# خارطة الطريق

تعتمد المراحل على أدلة واختبارات لا على وعود زمنية. لا تعد الميزة مكتملة إلا عندما يتفق التنفيذ والاختبارات والتوثيق.

## المرحلة صفر — تأسيس المستودع

- [x] حزمة Rust ونقطة دخول CLI واختبارات أولية.
- [x] كلمات عربية ومعرّفات Unicode وتشخيصات عربية.
- [x] قواعد أولية وتوثيق بالعربية والفرنسية والإنجليزية.
- [ ] نجاح CI في التنسيق والفحص والاختبارات والتحقق من ناتج المثال.
- [ ] توثيق عملية قرارات التصميم ومراجعتها.

## المرحلة الأولى — نواة اللغة

- [x] وضع حدود لحجم المصدر وعدد الرموز وعمق التحليل، ورفض النتائج العددية غير المنتهية.
- [x] إضافة هدف fuzzing شامل محدود المدة لواجهة المفسر العامة يعمل أسبوعيًا.
- [ ] إضافة fuzzing مخصص للمحلل النحوي ومجموعة معيارية للبرامج غير الصالحة.
- [x] اعتماد أساس معرّفات `XID_Start` و`XID_Continue` مثبت بإصدار محدد، مع السماح بالشرطة السفلية واختبارات تراجع للعربية والفارسية.
- [ ] حسم التطبيع وتحذيرات اختلاط الأبجديات والتشابه البصري وتشخيص محارف اتجاه النص، مع مجموعة توافق.
- [ ] إضافة الشروط والكتل والنطاقات المحلية بعد مراجعة الدلالات.
- [ ] تحديد دلالات الأعداد ورموز الأخطاء المخصصة للأدوات.
- [ ] تثبيت تشخيصات منظمة لتكامل المحررات.

## المرحلة الثانية — التجريدات

- [ ] الدوال والمعاملات وقيم الإرجاع.
- [ ] المجموعات والتكرار.
- [ ] الوحدات والاستيراد ونموذج الاعتماديات.
- [ ] تمرير الأخطاء ودلالات تشغيل الحلقات المستقبلية.
- [ ] مكتبة قياسية بسياسة استقرار واضحة.

## المرحلة الثالثة — الأدوات

- [ ] منسق شيفرة وتشخيصات واعية بالبنية.
- [ ] تنفيذ Language Server Protocol.
- [ ] دعم تلوين الشيفرة في المحررات.
- [ ] ملف حزم وحل اعتماديات قابل لإعادة الإنتاج.
- [ ] اختبارات أداء ومجموعة لمنع التراجع.

## المرحلة الرابعة — المترجم والبناء الذاتي

- [ ] مواصفات تمثيل وسيط ثابت.
- [ ] مقارنة المفسر وآلة بايت كود والمترجم الأصلي بمجموعة صحة مشتركة وقياسات قابلة لإعادة الإنتاج.
- [ ] تحديد ABI وواجهة الربط قبل وعود التوافق مع C.
- [ ] بناء مترجم بلغة Rust يستهدف منصة موثقة.
- [ ] اختبارات إقلاع متكررة قبل التفكير في مترجم مكتوب بلغة ركن.

## سياسة الإصدارات

يتطلب إصدار 0.1 نجاح CI ومراجعة مواصفات اللغة. ويتطلب 1.0 دلالات وحدات مستقرة وسياسات توافق وترحيل ومراجعة أمان وحدود موارد موثقة وعملية صيانة. البناء الذاتي ليس شرطًا للإصدار 1.0 ما لم يقرر سجل التصميم خلاف ذلك.
