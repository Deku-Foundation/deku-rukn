# خارطة الطريق

المراحل مرتبطة بأدلة واختبارات، لا بوعود زمنية. لا تعد الميزة مكتملة حتى تغطيها الاختبارات والوثائق.

## المرحلة صفر — تأسيس المستودع

- [x] حزمة Rust ونقطة دخول CLI واختبارات أولية.
- [x] كلمات عربية ومعرّفات Unicode وتشخيصات.
- [x] قواعد أولية وتوثيق بالعربية والفرنسية والإنجليزية.
- [ ] نجاح CI في التنسيق والفحص والاختبارات.
- [ ] توثيق عملية قرارات التصميم.

## المرحلة الأولى — نواة اللغة

- [ ] حدود لحجم المصدر وعدد الرموز وعمق التداخل.
- [ ] اختبار fuzzing ومجموعة برامج غير صالحة.
- [ ] تحديد تطبيع Unicode والتشابه البصري للمعرّفات.
- [ ] إضافة إذا/وإلا والكتل والنطاقات بعد مراجعة الدلالات.
- [ ] تحديد دلالات الأعداد والسياسة العددية.
- [ ] أخطاء منظمة برموز قابلة للاستهلاك الآلي.

## المرحلة الثانية — التجريدات

- [ ] الدوال وقيم الإرجاع.
- [ ] المجموعات والتكرار.
- [ ] الوحدات والاستيراد والاعتماديات.
- [ ] معالجة الأخطاء وحدود الموارد.
- [ ] مكتبة قياسية بسياسة استقرار واضحة.

## المرحلة الثالثة — الأدوات

- [ ] منسق شيفرة وتشخيصات واعية بالبنية.
- [ ] تنفيذ Language Server Protocol.
- [ ] دعم تلوين الشيفرة في المحررات.
- [ ] ملف حزم وحل اعتماديات قابل لإعادة الإنتاج.
- [ ] اختبارات أداء ومجموعة منع تراجع.

## المرحلة الرابعة — المترجم والبناء الذاتي

- [ ] مواصفات تمثيل وسيط ثابت.
- [ ] مقارنة المفسر وآلة البايت كود والمترجم الأصلي بقياسات.
- [ ] تحديد ABI وواجهة الربط قبل وعود التوافق مع C.
- [ ] مترجم مكتوب بـ Rust يستهدف منصة موثقة.
- [ ] اختبارات بناء متكرر قبل التفكير في مترجم مكتوب بلغة ركن.

الإصدار 1.0 يحتاج قواعد وحدات مستقرة وسياسة توافق وأمان وصيانة موثقة. البناء الذاتي ليس شرطًا للإصدار 1.0 ما لم يتقرر خلاف ذلك.
