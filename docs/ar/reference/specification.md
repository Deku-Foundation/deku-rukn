# مواصفات لغة ركن

**الحالة: مسودة 0.1.** تصف هذه الوثيقة المفسر الحالي فقط. أي سلوك غير مذكور هنا غير مدعوم.

## القواعد المعجمية

- ملفات المصدر بترميز UTF-8.
- يبدأ المعرّف بشرطة سفلية أو حرف Unicode أبجدي، ويمكن أن تتبعه أرقام Unicode.
- الكلمات المحجوزة: دع، اطبع، صحيح، خطأ، لاشيء.
- تدعم الأعداد أرقام ASCII والهندية والفارسية، والنقطة ASCII للفاصل العشري.
- النصوص تستخدم علامتي اقتباس مزدوجتين أو علامتي التنصيص العربيتين «نص».
- يبدأ التعليق بـ # وينتهي مع نهاية السطر.
- تنتهي التعليمة بالرمز ؛ أو ;.

## القواعد النحوية المختصرة

    program      = { statement } ;
    statement    = declaration | print_statement | expression_statement ;
    declaration  = "دع" identifier "=" expression terminator ;
    print_statement = "اطبع" [ "(" ] expression [ ")" ] terminator ;
    expression   = equality ;
    equality     = comparison { ("==" | "!=") comparison } ;
    comparison   = term { (">" | ">=" | "<" | "<=") term } ;
    term         = factor { ("+" | "-") factor } ;
    factor       = unary { ("*" | "/") unary } ;
    unary        = ("!" | "-") unary | primary ;
    primary      = number | string | "صحيح" | "خطأ" | "لاشيء"
                 | identifier | "(" expression ")" ;

## التقييم

- الأعداد من نوع f64 في Rust.
- لا يقبل + إلا عددين أو نصين.
- المقارنة العددية تتطلب عددين.
- المساواة تقارن القيم وأنواعها.
- استخدام متغير غير معرّف خطأ.
- القسمة على الصفر خطأ.
- تنفذ التعليمات بالترتيب وتُجمع مخرجات الطباعة.

## الفجوات المعروفة

لا توجد حتى الآن معالجة لتطبيع Unicode أو تشابه المعرّفات بصريًا أو نطاقات محلية أو نظام أنواع ساكن أو حدود موارد أو آلة بايت كود أو معيار توافق مستقر.
