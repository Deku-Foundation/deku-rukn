# مواصفات لغة ركن

**الحالة: مسودة 0.4.** تصف هذه الوثيقة المفسر الحالي فقط. أي سلوك غير مذكور هنا غير مدعوم.

## القواعد المعجمية

- ملفات المصدر بترميز UTF-8.
- يبدأ المعرّف بالشرطة السفلية أو محرف `XID_Start`، وتستخدم بقية المحارف `XID_Continue` أو الشرطة السفلية، عبر الاعتمادية المثبتة `unicode-ident 1.0.27` وفق UAX #31. تسمح القاعدة بعلامات التشكيل المدعومة بعد أول محرف.
- لا تُطبّع أسماء المعرّفات؛ ولا توجد حاليًا أداة لكشف التشابه البصري أو لتشخيص محارف اتجاه النص.
- الصيغة العلمية للأعداد ليست جزءًا من القواعد العددية الحالية.
- الكلمات المحجوزة: دع، اطبع، صحيح، خطأ، لاشيء، و، أو.
- تدعم الأعداد أرقام ASCII والهندية والفارسية. يمكن استخدام النقطة ASCII أو الفاصل العشري العربي ٫ (U+066B)، ويجب أن يتبعه رقم واحد على الأقل؛ وتُرفض الفواصل المتكررة. يجب أن تنتمي كل الأرقام في العدد الواحد إلى مجموعة واحدة؛ ويُرفض خلط المجموعات عند أول رقم مخالف.
- النصوص تستخدم علامتي اقتباس مزدوجتين أو علامتي التنصيص العربيتين «نص». تُرفض نهايتا السطر LF وCR داخل النص، حتى إذا سبقتهما شرطة هروب عكسية.
- يبدأ التعليق بـ # وينتهي مع نهاية السطر.
- تنتهي التعليمة بالرمز ؛ أو ;.

## القواعد النحوية المختصرة

    program      = { statement } ;
    statement    = declaration | print_statement | expression_statement ;
    declaration  = "دع" identifier "=" expression terminator ;
    print_statement = "اطبع" [ "(" ] expression [ ")" ] terminator ;
    expression   = logical_or ;
    logical_or   = logical_and { "أو" logical_and } ;
    logical_and  = equality { "و" equality } ;
    equality     = comparison { ("==" | "!=") comparison } ;
    comparison   = term { (">" | ">=" | "<" | "<=") term } ;
    term         = factor { ("+" | "-") factor } ;
    factor       = unary { ("*" | "/") unary } ;
    unary        = ("!" | "-") unary | primary ;
    primary      = number | string | "صحيح" | "خطأ" | "لاشيء"
                 | identifier | "(" expression ")" ;

## التقييم

- الأعداد من نوع f64 في Rust.
- لا يقبل + إلا عددين أو نصين.
- المقارنة العددية تتطلب عددين.
- المساواة تقارن القيم وأنواعها.
- العاملان و وأو يساريّا الترابط ويستخدمان التقييم قصير الدارة. يجب أن تكون نتيجة الطرف الأيسر قيمة منطقية. لا يُقيّم الطرف الأيمن ولا يُفحص نوعه وقت التشغيل إذا حسم الطرف الأيسر النتيجة؛ وإن جرى تقييمه فيجب أن تكون نتيجته منطقية. لا يوجد تحويل ضمني بين الأنواع.
- استخدام متغير غير معرّف خطأ.
- القسمة على الصفر خطأ.
- تُرفض النتائج العددية غير المنتهية بتشخيص لغوي.
- تنفذ التعليمات بالترتيب وتُجمع مخرجات الطباعة.

## حدود الموارد المنفذة

يفرض التنفيذ الحالي حدودًا عملية:

| المورد | الحد الحالي |
| --- | ---: |
| حجم المصدر | 1,048,576 بايت (1 MiB) |
| عدد الرموز المعجمية | 16,384 |
| عمق التداخل النحوي | 64 مستوى |
| حجم قيمة النص الواحدة | 1,048,576 بايت UTF-8 (1 MiB) |
| ميزانية تخصيص/نسخ النصوص التراكمية لكل تشغيل | 16,777,216 بايت (16 MiB) |

تحتسب الميزانية التراكمية نسخ قيم النصوص ونتائج ضمّ النصوص ومخرجات الطباعة التي يجمعها التنفيذ خلال تشغيل واحد. وهي محاسبة محافظة للتخصيصات والنسخ، وليست قياسًا دقيقًا لحجم الذاكرة الحية. تُرفض المدخلات التي تتجاوز هذه الحدود بخطأ لغوي. هذه حدود تنفيذ قابلة للتغيير قبل إصدار مستقر، وليست عزلًا رسميًا أو ضمانًا ضد كل أشكال استنزاف الموارد.

## الفجوات المعروفة

لم تُشتق القواعد بعد من تعريف نحوي رسمي. ما زال تطبيع Unicode وسياسة المعرّفات المتشابهة بصريًا والنطاقات المحلية والربط الثابت للمتغيرات ونظام الأنواع الساكن وآلة البايت كود ومجموعة توافق معيارية للغة أعمالًا مفتوحة قبل الإصدار المستقر.
