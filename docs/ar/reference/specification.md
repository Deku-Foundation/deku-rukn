# مواصفات لغة ركن

**الحالة: مسودة 0.7.** تصف هذه الوثيقة المفسر الحالي فقط. أي سلوك غير مذكور هنا غير مدعوم.

## القواعد المعجمية

- ملفات المصدر بترميز UTF-8.
- يبدأ المعرّف بالشرطة السفلية أو محرف `XID_Start`، وتستخدم بقية المحارف `XID_Continue` أو الشرطة السفلية، عبر الاعتمادية المثبتة `unicode-ident 1.0.27` وفق UAX #31. تسمح القاعدة بعلامات التشكيل المدعومة بعد أول محرف.
- لا تُطبّع أسماء المعرّفات؛ ولا توجد حاليًا أداة لكشف التشابه البصري أو لتشخيص محارف اتجاه النص.
- الصيغة العلمية للأعداد ليست جزءًا من القواعد العددية الحالية.
- الكلمات المحجوزة: دع، اطبع، دالة، أرجع، إذا، وإلا، بينما، صحيح، خطأ، لاشيء، و، أو.
- تدعم الأعداد أرقام ASCII والهندية والفارسية. يمكن استخدام النقطة ASCII أو الفاصل العشري العربي ٫ (U+066B)، ويجب أن يتبعه رقم واحد على الأقل؛ وتُرفض الفواصل المتكررة. يجب أن تنتمي كل الأرقام في العدد الواحد إلى مجموعة واحدة؛ ويُرفض خلط المجموعات عند أول رقم مخالف.
- النصوص تستخدم علامتي اقتباس مزدوجتين أو علامتي التنصيص العربيتين «نص». تُرفض نهايتا السطر LF وCR داخل النص، حتى إذا سبقتهما شرطة هروب عكسية.
- يبدأ التعليق بـ # وينتهي مع نهاية السطر.
- تنتهي التعليمة بالرمز ؛ أو ;.

## القواعد النحوية المختصرة

    program      = { statement } ;
    statement    = function_declaration | return_statement | declaration
                 | assignment | print_statement | if_statement | while_statement
                 | block | expression_statement ;
    function_declaration = "دالة" identifier "(" [ parameter_list ] ")" block ;
    parameter_list = identifier { "," identifier } ;
    return_statement = "أرجع" [ expression ] terminator ;
    declaration  = "دع" identifier "=" expression terminator ;
    assignment   = identifier "=" expression terminator ;
    print_statement = "اطبع" ( "(" expression ")" | expression ) terminator ;
    if_statement = "إذا" "(" expression ")" block [ "وإلا" block ] ;
    while_statement = "بينما" "(" expression ")" block ;
    block        = "{" { statement } "}" ;
    expression_statement = expression terminator ;
    expression   = logical_or ;
    logical_or   = logical_and { "أو" logical_and } ;
    logical_and  = equality { "و" equality } ;
    equality     = comparison { ("==" | "!=") comparison } ;
    comparison   = term { (">" | ">=" | "<" | "<=") term } ;
    term         = factor { ("+" | "-") factor } ;
    factor       = unary { ("*" | "/") unary } ;
    unary        = ("!" | "-") unary | primary ;
    primary      = number | string | "صحيح" | "خطأ" | "لاشيء"
                 | call_expression | identifier | "(" expression ")" ;
    call_expression = identifier "(" [ argument_list ] ")" ;
    argument_list = expression { "," expression } ;

## التقييم

- الأعداد من نوع f64 في Rust.
- لا يقبل + إلا عددين أو نصين.
- المقارنة العددية تتطلب عددين.
- المساواة تقارن القيم وأنواعها.
- العاملان و وأو يساريّا الترابط ويستخدمان التقييم قصير الدارة. يجب أن تكون نتيجة الطرف الأيسر قيمة منطقية. لا يُقيّم الطرف الأيمن ولا يُفحص نوعه وقت التشغيل إذا حسم الطرف الأيسر النتيجة؛ وإن جرى تقييمه فيجب أن تكون نتيجته منطقية. لا يوجد تحويل ضمني بين الأنواع.
- تنشئ «دع» ربطًا في النطاق المحلي الحالي، وتستبدل ربطًا سابقًا بالاسم نفسه في النطاق نفسه.
- تنشئ الكتل المحاطة بـ {} نطاقات محلية. يبحث المفسر عن الاسم من النطاق الأعمق إلى الخارج؛ ولا يتسرب المتغير المحلي بعد انتهاء الكتلة.
- يحدّث الإسناد أقرب ربط موجود. الإسناد إلى اسم غير معرّف خطأ، والإسناد تعليمة وليس تعبيرًا.
- يجب أن ينتج الشرط في «إذا» و«بينما» قيمة منطقية؛ ولا يوجد تحويل ضمني إلى قيمة منطقية.
- يفحص المفسر شروط «بينما» بالترتيب، ويرفض التشغيل بعد 1,000,000 تقييم لشروط الحلقات إجمالًا للحد من الحلقات المنفلتة.
- تُعرّف الدوال بالصيغة `دالة اسم(معامل, ...)`، ولا يسمح بتعريفها إلا في المستوى الأعلى في هذه النسخة. تُسجّل أسماء الدوال قبل التنفيذ، لذا تعمل الإحالات إلى دوال تُعرّف لاحقًا والعودية المتبادلة. ويُرفض تكرار اسم الدالة أثناء التحليل. إذا لم يحجب متغير محلي الاسم، فإن الإشارة إلى اسم دالة تنتج قيمة مرجعية للدالة؛ ويمكن تخزين هذه القيمة في متغير أو تمريرها كوسيط أو إرجاعها من دالة. تتساوى مراجع الدالة التي تشير إلى الاسم نفسه. تستخدم الاستدعاءات الصيغة `اسم(...)`، لذا يمكن استدعاء الاسم المستعار، لكن لا يمكن بعد ربط استدعاء مُعاد مباشرة باستدعاء آخر دون تخزينه في متغير. لا تلتقط مراجع الدوال بيئة المتغيرات؛ فالإغلاقات وتعريف الدوال المتداخلة غير مدعومين.
- تُقيّم الوسائط من اليسار إلى اليمين في بيئة المستدعي. يجب أن يتطابق عدد الوسائط مع عدد المعاملات، والحد الأقصى 64.
- تعمل الدالة ببيئة المتغيرات العامة وبيئة جديدة للمعاملات والمتغيرات المحلية. لا تلتقط متغيرات الكتل عند المستدعي؛ فالإغلاقات وتعريف الدوال المتداخلة غير مدعومين. يستمر أي إسناد إلى متغير عام بعد انتهاء الاستدعاء.
- تعيد `أرجع تعبير؛` قيمة، بينما تعيد `أرجع؛` القيمة `لاشيء`. كما تعيد الدالة `لاشيء` إذا انتهت دون إرجاع صريح. استخدام «أرجع» خارج دالة خطأ.
- تدعم الدوال الاستدعاء الذاتي بعمق أقصى 128 استدعاءً نشطًا. ويُحدّ عمق التعابير بشكل مستقل داخل إطار كل دالة.

## حدود الموارد المنفذة

يفرض التنفيذ الحالي حدودًا عملية:

| المورد | الحد الحالي |
| --- | ---: |
| حجم المصدر | 1,048,576 بايت (1 MiB) |
| عدد الرموز المعجمية | 16,384 |
| عمق التداخل النحوي | 64 مستوى |
| حجم قيمة النص الواحدة | 1,048,576 بايت UTF-8 (1 MiB) |
| ميزانية تخصيص/نسخ النصوص التراكمية لكل تشغيل | 16,777,216 بايت (16 MiB) |
| عدد تقييمات شروط «بينما» لكل تشغيل | 1,000,000 |
| عمق استدعاء الدوال النشط | 128 |
| عدد معاملات الدالة أو وسائط الاستدعاء | 64 |

تحتسب الميزانية التراكمية نسخ قيم النصوص وأسماء مراجع الدوال المسماة ونتائج ضمّ النصوص ومخرجات الطباعة التي يجمعها التنفيذ خلال تشغيل واحد. وهي محاسبة محافظة للتخصيصات والنسخ، وليست قياسًا دقيقًا لحجم الذاكرة الحية. تُرفض المدخلات التي تتجاوز هذه الحدود بخطأ لغوي. هذه حدود تنفيذ قابلة للتغيير قبل إصدار مستقر، وليست عزلًا رسميًا أو ضمانًا ضد كل أشكال استنزاف الموارد.

## الفجوات المعروفة

لم تُشتق القواعد بعد من تعريف نحوي رسمي. ما زال تطبيع Unicode وسياسة المعرّفات المتشابهة بصريًا والربط غير القابل للتغيير ونظام الأنواع الساكن والإغلاقات والمجموعات والوحدات والتمثيل الوسيط ذي الأنواع وآلة البايت كود ومجموعة توافق مشتركة بين المفسر وآلة البايت كود والمترجم أعمالًا مفتوحة قبل الإصدار المستقر.
