# بنية المفسر

ركن حاليًا مفسر شجري صغير مكتوب بـ Rust الآمن. يتجنب التنفيذ عمدًا توليد الشيفرة الأصلية والاعتماد على وقت تشغيل خارجي.

```text
مصدر UTF-8
    ↓
محلل معجمي — رموز مع السطر والعمود
    ↓
محلل تنازلي تكراري — شجرة التعليمات والتعابير
    ↓
مقيّم — بيئة المتغيرات والقيم
    ↓
مخرجات مجمعة أو خطأ لغوي محدد الموقع
```

## المكونات

- **المحلل المعجمي:** يكتشف علامات الترقيم والمعرّفات والأعداد والنصوص والتعليقات والكلمات العربية.
- **المحلل النحوي:** يطبق أولوية العمليات بالتحليل التنازلي التكراري، ويحدّ عمق التداخل.
- **المقيّم:** ينفذ التعليمات حسب ترتيب المصدر. القيم أعداد ونصوص ومنطقية وقيمة شبيهة بالعدم؛ وتصدر تشخيصات عند خلط الأنواع أو إنتاج نتيجة عددية غير منتهية.
- **واجهة الأوامر:** تقرأ ملف مصدر UTF-8 واحدًا، وتطبع النتائج في stdout والأخطاء في stderr مع رمز خروج غير صفري.
- **الاختبارات:** تغطي الرموز العربية وتطبيع الأرقام وأولوية العمليات وأخطاء الأنواع والأسماء غير المعروفة والمدخلات المشوهة وحدود الموارد.

## حدود الموارد المنفذة

يحدد التنفيذ الحالي حدودًا واضحة لحجم المصدر وعدد الرموز وعمق التحليل. وترفض اللغة المصدر الزائد أو تجاوز عدد الرموز أو التعابير شديدة التداخل بأخطاء لغوية. كما ترفض العمليات العددية النتائج غير المنتهية بدل تمرير ما لا نهاية أو NaN بصمت.

هذه حواجز عملية وليست عزلًا رسميًا أو ضمانًا ضد كل أشكال استنزاف الموارد. ينبغي أن تبقى موثقة ومشمولة باختبارات منع التراجع عند تعديلها.

## حدود الأمان

لا تتضمن اللغة واجهات ملفات أو شبكة أو عمليات على مستوى اللغة، ولا تحمّل إضافات أصلية. تقرأ واجهة الأوامر ملف المصدر المحدد فقط. يقلل ذلك سطح الهجوم، لكنه لا يشكل ضمان عزل رسميًا.

لا تدمج برامج غير موثوقة داخل خدمة متعددة المستخدمين ذات صلاحيات مرتفعة دون نموذج تهديد منفصل وعزل على مستوى العمليات ومراقبة للموارد ومراجعة لحدود دمج المفسر.

## لماذا Rust أولًا؟

توفر Rust أنواعًا تعدادّية للرموز والقيم، ومعالجة صريحة للأخطاء، وافتراضات قوية لسلامة الذاكرة، ومنظومة بناء واختبار ناضجة. Rust لغة تنفيذ ركن وليست شرطًا لفرض صياغتها أو دلالاتها على اللغة المستقبلية.

## أسئلة تصميم مفتوحة

- تطبيع Unicode وعلامات التشكيل العربية والمعرّفات المتشابهة بصريًا.
- الكلمات المحجوزة وتفاعل المعرّفات مع الصياغة المستقبلية.
- قواعد الأنواع وتغيير المتغيرات والنطاقات المحلية.
- الدوال والوحدات وتمرير الأخطاء.
- تنسيق الحزم والوحدات واستقرار المكتبة القياسية.
- المفسر الشجري أم آلة بايت كود أم توليد شيفرة أصلية.
- واجهة الربط مع اللغات الأخرى وسياسة ABI.
- خطوات إقلاع المترجم والبناء الذاتي.

يُبحث البناء الذاتي فقط بعد استقرار القواعد والمكتبة القياسية والتشخيصات ومجموعة التوافق وخطة الإقلاع الأولية. وجود مترجم مكتوب بلغة ركن لا يثبت وحده الأمان أو الأداء أو جودة اللغة.
