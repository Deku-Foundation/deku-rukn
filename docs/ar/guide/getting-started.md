# التثبيت والتشغيل

يعمل ركن حاليًا من المصدر باستخدام سلسلة أدوات Rust. لا توجد إصدارات ثنائية رسمية بعد.

## المتطلبات

- سلسلة أدوات Rust المستقرة مع دعم Edition 2024.
- Git.
- طرفية تدعم UTF-8 وخطًا يعرض العربية.

## البناء والاختبار

    git clone https://github.com/Deku-Foundation/deku-rukn.git
    cd deku-rukn
    cargo test --locked
    cargo build --release --locked
    cargo run --locked -- examples/hello.rukn
    cargo run --locked -- examples/functions.rukn

الناتج المتوقع لمثال hello.rukn:

    مرحبًا يا العالم
    42
    خطأ

## كتابة برنامج

    # يبدأ التعليق بعلامة #
    دع الاسم = «العالم»؛
    اطبع(«مرحبًا يا » + الاسم)؛
    دع العدد = ٦ * ٧؛
    اطبع(العدد)؛

أنهِ كل تعليمة بالرمز ؛ أو ;. لا يقبل البرنامج التنفيذي إلا ملف مصدر واحدًا في هذه النسخة.

## عند حدوث خطأ

- استخدم سلسلة Rust حديثة تدعم Edition 2024.
- إذا ظهرت العربية بشكل غير صحيح، جرّب طرفية وخطًا يدعمان تشكيل الحروف.
- تعرض الأخطاء السطر والعمود ورسالة عربية.
- تدعم النواة الدوال المسماة ومراجعها كقيم واستدعاء الدوال الأعلى رتبة والمعاملات والإرجاع والعودية. لم تنفذ بعد الإغلاقات والوحدات/الاستيراد والمجموعات والوصول من اللغة إلى الملفات والشبكة أو آلة بايت كود أو مترجمًا أصليًا.
