# دليل اللغة

تشرح هذه الصفحة ما ينفذه المفسر فعلًا، لا كامل الرؤية المستقبلية.

## المتغيرات والطباعة

    دع الاسم = «ليلى»؛
    دع السعر = 12.5؛
    اطبع(الاسم)؛
    اطبع(السعر * 2)؛

تنتهي كل تعليمة بالرمز ؛ أو ;. تدعم الأعداد الأرقام العربية الهندية والفارسية وASCII. يقبل الفاصل العشري النقطة ASCII أو الرمز العربي ٫ (U+066B)، ويجب أن يتبعه رقم واحد على الأقل. يجب أن تنتمي أرقام العدد الواحد إلى مجموعة واحدة فقط؛ ويؤدي خلط أرقام ASCII والهندية والفارسية في العدد نفسه إلى خطأ.

## الإسناد والنطاقات المحلية

استخدم `=` في تعليمة مستقلة لتحديث متغير موجود؛ الإسناد إلى اسم غير معرّف خطأ. إذا تكرر الاسم في نطاقات متداخلة، يحدّث الإسناد أقرب ربط موجود بدءًا من النطاق الداخلي.

تنشئ الكتل المحاطة بالأقواس المعقوفة نطاقًا محليًا. لا يبقى المتغير المعرّف داخل الكتلة متاحًا بعد انتهائها. ويؤدي تعريف الاسم نفسه داخل كتلة متداخلة إلى حجب الربط الخارجي، أما تعريفه مجددًا في النطاق نفسه فيستبدل الربط الحالي في ذلك النطاق.

```rukn
دع الاسم = «خارج»؛
{
    دع الاسم = «داخل»؛
    الاسم = «معدّل»؛
    اطبع(الاسم)؛
}
اطبع(الاسم)؛
```

الناتج:

```text
معدّل
خارج
```

## الشروط والحلقات

تختار `إذا` كتلة التنفيذ عندما تكون النتيجة `صحيح`، ويمكن إضافة `وإلا` للكتلة البديلة. تكرر `بينما` كتلتها ما دام الشرط ينتج `صحيح`. يجب أن تكون الشروط منطقية؛ لا يتحول العدد أو النص تلقائيًا إلى قيمة منطقية.

```rukn
دع العد = ٠؛
بينما (العد < ٣) {
    اطبع(العد)؛
    العد = العد + ١؛
}
إذا (العد == ٣) {
    اطبع(«انتهى»)؛
} وإلا {
    اطبع(«لم ينتهِ»)؛
}
```

الناتج:

```text
0
1
2
انتهى
```

يوقف المفسر التشغيل بعد 1,000,000 تقييم إجمالي لشروط `بينما`. هذا حد موارد في التنفيذ وليس ضمانًا زمنيًا أو عزلًا كاملًا.

## الدوال والمعاملات والإرجاع

تُعرّف الدالة بالكلمة العربية `دالة` ثم الاسم وقائمة معاملات تفصل بينها الفاصلة اللاتينية `,` وجسم محاط بأقواس معقوفة. يُستدعى الاسم بالأقواس، ويجب أن يطابق عدد الوسائط عدد المعاملات المعلنة.

```rukn
دالة جمع(أ, ب) {
    أرجع أ + ب؛
}

دالة عاملي(ن) {
    إذا (ن <= ١) {
        أرجع ١؛
    }
    أرجع ن * عاملي(ن - ١)؛
}

اطبع(جمع(٢٠, ٢٢))؛
اطبع(عاملي(٥))؛
```

الناتج المتوقع:

```text
42
120
```

تعيد `أرجع تعبير؛` قيمة، بينما تعيد `أرجع؛` القيمة `لاشيء`. وكذلك تعيد الدالة `لاشيء` إذا انتهت دون إرجاع صريح. الإرجاع خارج الدالة خطأ. في هذه النسخة لا تُعرّف الدوال إلا في المستوى الأعلى، ويدعم الاستدعاء الذاتي حتى 128 استدعاءً نشطًا، ولا يزيد عدد المعاملات أو الوسائط على 64.

الدوال أسماء قابلة للاستدعاء وليست قيمًا من الدرجة الأولى؛ فلا يمكن تخزينها في متغير أو إرجاعها، ولا يُسمح بتعريف دالة داخل أخرى، ولا تلتقط الدالة المتغيرات المحلية لدى المستدعي. الإغلاقات والوحدات ونظام الأنواع الساكن أعمال مستقبلية.

## القيم

| النوع | أمثلة |
| --- | --- |
| عدد | 42، ٣.٥ |
| نص | "hello"، «أهلًا» |
| منطقي | صحيح، خطأ |
| عدم | لاشيء |

## العمليات

- +: جمع عددين أو ضم نصين من النوع نفسه.
- -: طرح أو نفي عدد.
- * و/: ضرب وقسمة.
- < و<= و> و>=: مقارنة عددية.
- == و!=: مقارنة المساواة.
- !: نفي قيمة منطقية.
- و: اقتران منطقي يتطلب قيمتين منطقيتين؛ إذا كانت اليسرى خطأ فلا يُقيّم الطرف الأيمن.
- أو: فصل منطقي يتطلب قيمتين منطقيتين؛ إذا كانت اليسرى صحيح فلا يُقيّم الطرف الأيمن.

ترتيب الأولوية من الأعلى: النفي، ثم الضرب والقسمة، ثم الجمع والطرح، ثم المقارنة، ثم المساواة، ثم و، ثم أو. العاملان المنطقيان يساريّا الترابط ويستخدمان التقييم قصير الدارة. يجب أن تكون نتيجة الطرف الأيسر قيمة منطقية. لا يُقيّم الطرف الأيمن ولا يُفحص نوعه وقت التشغيل إذا حسم الطرف الأيسر النتيجة؛ وإن جرى تقييمه فيجب أن تكون نتيجته منطقية. لا يوجد تحويل ضمني بين الأنواع. يمكن تغيير الأولوية باستخدام الأقواس.

    اطبع(صحيح أو خطأ و خطأ)؛ # صحيح: أولوية و أعلى من أو
    اطبع(خطأ و (١ / ٠ == ٠))؛ # خطأ؛ لا تُنفذ القسمة

## التعليقات والأخطاء

يبدأ التعليق بعلامة # ويستمر حتى نهاية السطر. المتغير غير المعرّف، والنص غير المغلق، والمحرف غير المدعوم، والقسمة على صفر، واختلاف أنواع القيم تنتج أخطاء مع السطر والعمود. لا يحدث تحويل ضمني للأنواع.


## ميزات لم تُنفذ بعد

لم تُنفذ الإغلاقات والدوال كقيم من الدرجة الأولى والمجموعات والأنواع المعرفة من المستخدم والوحدات وصياغة معالجة الأخطاء ونظام الأنواع الساكن وواجهة ABI مستقرة بعد. أما الدوال المسماة ومعاملاتها والإرجاع والعودية والشروط والكتل والنطاقات المحلية والإسناد وحلقات `بينما` المحدودة فهي مدعومة تجريبيًا. راجع المواصفات وخارطة الطريق.


## معرّفات Unicode

تستخدم المعرّفات خاصيتي Unicode `XID_Start` و`XID_Continue` عبر الاعتمادية المثبتة `unicode-ident 1.0.27`، مع السماح المتعمد بالشرطة السفلية (`_`) في البداية أو الاستمرار. يستند هذا الأساس المعجمي إلى [الملحق Unicode UAX #31](https://www.unicode.org/reports/tr31/).

تُقبل الحروف العربية والفارسية، وكذلك علامات التشكيل عندما تسمح بها قاعدة XID بعد أول محرف:

```rukn
دع عَلم = ٧؛
اطبع(عَلم)؛
دع پ = ۳؛
اطبع(پ)؛
```

لا يجري **تطبيع أسماء المعرّفات** حاليًا. ولا نضمن أن الأسماء المتكافئة قانونيًا أو المتشابهة بصريًا تشير إلى المتغير نفسه. ما زالت سياسة التطبيع والتحذير من التشابه البصري ومحارف اتجاه النص غير المرئية مسائل بحث مفتوحة؛ راجع [Unicode وأمان المعرّفات](/ar/reference/unicode-and-security). تحديث بيانات المعرّفات يُعد تغييرًا في سلوك اللغة ويتطلب اختبارات توافق.
