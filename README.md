# Rukn — لغة برمجة عربية أولًا

Rukn is an experimental Arabic-first programming language and toolchain, built in Rust. The project starts with a small, testable interpreter and a precise language specification; it does not claim self-hosting or production readiness.

## Project status

The repository is being bootstrapped. The first milestone is a deterministic lexer, parser, evaluator, command-line runner, test suite, and Arabic-first documentation. Self-hosting is a later research milestone, not a current capability.

## Development

The implementation and language reference will live in this repository. See the roadmap and design documents as they land.
